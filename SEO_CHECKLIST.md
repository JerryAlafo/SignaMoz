## 📋 Próximas Ações (Manuais - Críticas)

### 1. Google Search Console ⭐ URGENTE

```
1. Acesse: https://search.google.com/search-console
2. Clique em "Adicionar propriedade"
3. Selecione "URL prefix"
4. Digite: https://signa-moz.vercel.app
5. Escolha o método de verificação (Arquivo HTML)
6. Copie o código de verificação
7. Em "layout.tsx", procure por: your-google-verification-code
8. Substitua pelo código recebido
9. Faça deploy
10. Volte ao Google Search Console e clique "Verificar"
```

### 2. Bing Webmaster Tools ⭐ URGENTE

```
1. Acesse: https://www.bing.com/webmaster/configure
2. Adicione seu site: https://signa-moz.vercel.app
3. Escolha verificação por metatag
4. Copie o código
5. Em "layout.tsx", procure por: your-bing-verification-code
6. Substitua pelo código recebido
7. Faça deploy
```

### 3. Submeter Sitemap

- Google Search Console → Sitemaps → Adicione: https://signa-moz.vercel.app/sitemap.xml
- Bing Webmaster → Sitemaps → Adicione: https://signa-moz.vercel.app/sitemap.xml

### 4. Google Analytics (Recomendado)

```
1. Crie uma conta em: https://analytics.google.com
2. Configure para seu domínio
3. Copie o ID de rastreamento
4. Adicione script de Google Analytics no layout.tsx
```

### 5. Otimização de Imagens

- Adicione imagem OG tag: `/public/og-image.png` (1200x630px)
- Adicione favicon: `/public/favicon.ico`
- Adicione ícones PWA: `/public/icon-192.png` e `/public/icon-512.png`
