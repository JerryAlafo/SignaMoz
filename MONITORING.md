## 🚨 Red Flags (Watch Out For)

Se ver algum destes, investigue:

```
⚠️ Drops de tráfego > 20%
   → Check Google Search Console para algoritmo updates
   → Revisar técnica SEO
   → Checar penalizações

⚠️ Ranking cai após "subir"
   → Conteúdo duplicado?
   → Backlinks ruins?
   → Mudança de algoritmo?

⚠️ Impressões mas zero cliques
   → Meta description ruim
   → Página não tão relevante
   → Snippet desatrativo

⚠️ Muitos Crawl Errors
   → Links quebrados
   → Redirects incorretos
   → Robots.txt muito restritivo
```
