# Guia Simples do SignaMoz

## O que é o SignaMoz?

O SignaMoz é um aplicativo que ajuda pessoas que usam linguagem de sinais a se comunicarem com pessoas que não sabem sinais. Ele usa a câmera do seu dispositivo para "ver" os gestos que você faz e transforma eles em palavras escritas em português.

O aplicativo entende duas linguagens de sinais:

- **Libras**: Usada no Brasil
- **Língua Gestual Moçambicana**: Usada em Moçambique

## Como funciona o sistema?

1. **Você liga a câmera**: O aplicativo usa a câmera para ver seus gestos em tempo real.

2. **Ele reconhece os movimentos**: A câmera identifica onde estão suas mãos, rosto e corpo.

3. **Transforma em palavras**: Uma inteligência artificial analisa os gestos e tenta descobrir qual palavra você está fazendo.

4. **Constrói frases**: As palavras vão aparecendo uma por uma, formando uma frase completa.

5. **Você pode usar fotos ou vídeos**: Se preferir, pode tirar uma foto ou gravar um vídeo dos gestos para análise.

## Como usar cada botão

### Botões principais na tela inicial

#### ▶️ **Iniciar captura**

- **O que faz**: Liga a câmera e começa a detectar seus gestos automaticamente.
- **Como usar**: Clique neste botão para começar. A câmera vai mostrar o que está vendo e começar a tentar reconhecer gestos.
- **Dica**: Use a câmera frontal do celular para gestos pessoais, ou traseira para mostrar gestos para outras pessoas.

#### 🔄 **Tentar novamente**

- **O que faz**: Aparece quando algo dá errado. Tenta reiniciar a captura.
- **Como usar**: Só aparece se houver um erro. Clique para tentar de novo.

#### 📷 **Usar traseira/frontal**

- **O que faz**: Troca entre a câmera de trás e a de frente do seu dispositivo.
- **Como usar**: Só funciona quando a captura está ligada. Clique para mudar de câmera.

#### 📸 **Capturar foto**

- **O que faz**: Tira uma foto do que a câmera está vendo no momento.
- **Como usar**: Só funciona quando a captura está ligada. A foto aparece na tela para você ver.

#### 🎥 **Gravar vídeo / ⏹️ Parar gravação**

- **O que faz**: Começa ou para de gravar um vídeo dos gestos.
- **Como usar**: Clique "Gravar vídeo" para começar a gravar. Clique "Parar gravação" para terminar. O vídeo fica salvo para você analisar depois.

#### ⏹️ **Parar**

- **O que faz**: Desliga a câmera e para de detectar gestos.
- **Como usar**: Clique quando quiser parar de usar a câmera.

#### 🔄 **Limpar frase**

- **O que faz**: Apaga todas as palavras que foram detectadas e começa uma frase nova.
- **Como usar**: Clique quando quiser recomeçar a frase do zero.

### Botões de upload

#### 📁 **Upload imagem**

- **O que faz**: Permite você escolher uma foto salva no seu dispositivo para analisar.
- **Como usar**: Clique no botão, escolha uma foto. O aplicativo vai tentar reconhecer gestos na imagem.

#### 🎥 **Upload vídeo**

- **O que faz**: Permite você escolher um vídeo salvo no seu dispositivo para analisar.
- **Como usar**: Clique no botão, escolha um vídeo. O aplicativo vai analisar os gestos no vídeo.

### Outros controles

#### Seleção de idioma

- **O que faz**: Escolhe qual linguagem de sinais você quer usar.
- **Como usar**: Clique na caixa e escolha "Libras (Brasil)" ou "Língua Gestual Moçambicana".

#### ☑️ **Usar análise de imagem apenas com Vision AI**

- **O que faz**: Muda como o aplicativo analisa imagens e vídeos.
- **Como usar**: Marque ou desmarque a caixinha. Quando marcado, usa um método diferente para analisar fotos e vídeos.

## O que aparece na tela

### Palavra atual

- Mostra a última palavra que o aplicativo conseguiu reconhecer dos seus gestos.

### Frase em construção

- Mostra todas as palavras juntas, formando uma frase completa.

### Status

- Mostra o que o aplicativo está fazendo no momento (ex: "Capturando gestos...", "Consultando IA...", etc.).

## Dicas para usar melhor

- **Luz boa**: Use em lugares bem iluminados para o aplicativo ver melhor seus gestos.
- **Fundo simples**: Evite fundos muito coloridos ou movimentados.
- **Mãos visíveis**: Certifique-se de que suas mãos estão bem na frente da câmera.
- **Gestos firmes**: Faça os gestos de forma clara e não muito rápida.
- **Câmera certa**: Para gestos pessoais, use a câmera frontal. Para mostrar para outros, use a traseira.

## Privacidade

- Nada do que você faz fica guardado. Tudo some quando você fecha ou atualiza a página.
- O aplicativo não salva suas fotos, vídeos ou frases.

## Quando usar cada modo

- **Captura em tempo real**: Para conversar ao vivo, fazendo gestos na hora.
- **Foto**: Para analisar um gesto específico que você já fez.
- **Vídeo**: Para analisar uma sequência de gestos gravada.

## Problemas comuns

- **"Nenhuma mão detectada"**: Certifique-se de que suas mãos estão visíveis e bem iluminadas.
- **Palavras erradas**: Tente fazer o gesto mais devagar e claro.
- **Câmera não liga**: Permita o acesso à câmera quando o navegador pedir.
- **No celular**: Use um navegador que suporte câmera (Chrome, Safari) e certifique-se de usar HTTPS.
